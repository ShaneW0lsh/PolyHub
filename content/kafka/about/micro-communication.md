---
title: Как общаются микросервисы?
weight: 2
---

Каждый микросервис лежит на своем порте. Понятное дело, пользователь не сможет запомнить порт для каждой единицы бизнес логики, поэтому используется такая прекрасная вещь, называется API Gateway. 

Вместе с ним идут еще два приложения: Config Server - хранит конфигурации микросервисов, и Discovery Server - хранит маппинг имени микроса с его адресом. 

Данное трио обеспечивает слаженную работу микросервисов.

![](../img/trio.png)

Это и есть микросервисное приложение, если мы его реализуем на Spring Cloud. Если же мы будем это создавать и конфигурировать через Kubernetes, то будет примерно все то же самое, только использоваться будут не Springboot App, а конфиги кубера.
